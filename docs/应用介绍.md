## 三、应用介绍（AGC「应用介绍」字段，可直接粘贴）

```
【专为桂林旅游学院打造】

GLTU 课表是一款面向桂林旅游学院学生的课程表工具。它直接对接学校教务系统，
登录一次即可把整学期课表抓取下来，不用一节课一节课手动录入。

课表按课程自动配色，同一门课颜色固定，一眼就能认出是哪门。
支持周视图与日视图切换，支持手动添加、编辑、删除单门课程。


【节假日自动屏蔽 + 调休智能识别】

这是本应用最用心的地方。

· 法定节假日、学校假期、周末 —— 三个开关独立控制，
  想在上课的周末看到课，想屏蔽调休周的课，都能自己调

· 调休补班日会自动识别。国庆、五一前后的补班周末，
  应用知道那天要照常上课，而且上的是"被替代那一天"的课
  （比如 10 月 11 日周六补 10 月 8 日周三的课，就显示第 6 周周三的课程）

· 如果学校安排了临时调课，还能手动指定某个补班日补周几的课

节假日数据可联网自动同步，也会内置一份，断网也能正常用。


【桌面卡片，不用打开应用就能看课】

提供三种规格的桌面服务卡片，按需选择：

· 2×2 小卡片 —— 只显示下一节课
· 2×4 中卡片 —— 显示今天的课程列表
· 4×4 大卡片 —— 完整周课表

卡片每小时自动刷新。每天晚上 23:30 之后自动切换到第二天的课程，
第二天早上解锁手机，看到的就是今天要上的课。
当天最后一节课结束后，卡片会提示"今天的课都上完啦，好好休息"。


【上课前准时提醒】

可自行设置多个提醒时间点（1～60 分钟，支持同时设置多个），
每一节课上课前都会推送通知，再也不会因为看错时间而迟到。

还能把整学期课表一键同步到手机系统日历，
和你的日程、会议放在一起看，重复点击会先清理上次同步的条目，不会产生重复。


【周次管理】

· 忘了开学日期？没关系。直接告诉应用"这周是第几周"，
  它会自动反推开学日期，单双周、不规则周次都能正确显示

· 支持设置学期名称、每周起始日、课表显示到第几节


【个性化】

支持自定义课表背景图 —— 从相册选一张喜欢的图，
裁剪、缩放、拖动到满意为止，配合半透明课程块，课表也能很好看。


【全本地运行，数据不出手机】

本应用完全在本地运行，没有自建服务器，不上传任何用户数据。

需要联网的场景只有两个：
· 登录学校教务系统抓取课表（数据只保存在本机）
· 拉取公开的节假日数据

除此之外，你的课表、课表截图、背景图全部只存在你自己的手机上。
应用不申请通讯录、位置、相机等与功能无关的权限。


【关于】

开发者：木下葵
适用学校：桂林旅游学院（GLTU）
适用系统：HarmonyOS NEXT

如果你在使用中遇到问题，或者有功能建议，欢迎反馈。
```

## 七、隐私政策要点（写你自己的隐私政策时参考）

> 写隐私政策时以下几条照实写即可，AGC 审核会逐条核对。

### ⚠️ 权限声明必须与包内一字不差

AGC 提交时会自动比对「HAP 里 `module.json5` 申请的权限」和「隐私政策里声明的权限」，
**多写或少写都会被拦下**，报错形如：

```
检测到当前软件包user_grant类型的权限与隐私政策中声明的权限不一致，请修改后提交。
只在软件包中的权限：[...]     ← 申请了但没写，补上
只在隐私政策中的权限：[...]   ← 写了但没申请，删掉
```

**注意只比对 `user_grant`（运行时弹窗授权）类型的权限，`system_grant` 不用写。**

本应用 6 个权限的分类：

| 权限 | 类型 | 隐私政策要不要写 |
|---|---|---|
| `ohos.permission.INTERNET` | system_grant | 不用 |
| `ohos.permission.GET_NETWORK_INFO` | system_grant | 不用 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | system_grant | 不用 |
| `ohos.permission.READ_PASTEBOARD` | **user_grant** | ★ 必须写 |
| `ohos.permission.READ_CALENDAR` | **user_grant** | ★ 必须写 |
| `ohos.permission.WRITE_CALENDAR` | **user_grant** | ★ 必须写 |

**user_grant 三条的推荐措辞（可直接复制）：**

```
【读取粘贴板】ohos.permission.READ_PASTEBOARD
用途：读取用户复制的课表分享码，用于导入他人分享的课程表。
仅在用户主动点击「粘贴分享码」时读取，不后台读取、不上传。

【读取日历】ohos.permission.READ_CALENDAR
用途：将课表同步到系统日历时，先读取并清理上一次由本应用写入的日历条目，
避免重复添加。仅读取本应用自己创建的事件，不读取用户其他日程内容。

【写入日历】ohos.permission.WRITE_CALENDAR
用途：将课表写入系统日历，便于与用户其他日程统一查看。
仅在用户主动点击「同步到手机日历」时写入。
```

### ❌ 常见多余项：不要声明 READ_IMAGEVIDEO

本应用的「个性换肤」选背景图用的是**系统相册选择器**（`PhotoViewPicker`），
它只把用户手动选中的那一张图交给应用，**不需要申请相册读取权限**。

所以**不要**在隐私政策里声明 `ohos.permission.READ_IMAGEVIDEO`。
若想保留该功能的文字说明，用下面这段：

```
【选择课表背景图】
用户可从相册选择一张图片作为课表背景。本功能使用系统相册选择器，
应用仅获得用户主动选中的那一张图片，不读取、不访问相册中的其他内容，
所选用图片仅保存在本机。
```

### 其他条目

| 项目 | 说明 |
|---|---|
| 收集的个人信息 | **不收集** |
| 数据存储位置 | 仅在用户设备本地 |
| 数据共享 | **不与任何第三方共享** |
| 网络访问用途 1 | 登录学校教务系统抓取课表（凭据与课表仅存本机） |
| 网络访问用途 2 | 获取公开的节假日数据 |
| 用户数据删除 | 卸载应用即彻底删除；应用内也可手动删除课程与背景图 |
