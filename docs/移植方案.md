# 移植方案：Android → 纯血鸿蒙（HarmonyOS NEXT）

本文记录 Android 版 [GltuSchedule](https://github.com/LTYksa/GltuSchedule) 移植到纯血鸿蒙的
**完整功能对照表、当前进度、以及剩下的活怎么干**。

---

## 一、为什么必须重写

纯血鸿蒙（HarmonyOS NEXT / 5.0 起）**移除了 AOSP 兼容层**：

| | Android 版 | 纯血鸿蒙 |
|---|---|---|
| 安装包 | `.apk` | `.hap`（App Pack 为 `.app`） |
| 运行 APK | ✅ | ❌ **完全装不上** |
| 语言 | Kotlin / Java | **ArkTS**（TypeScript 方言） |
| UI 框架 | Jetpack Compose | **ArkUI**（声明式，`@Component` struct） |
| 开发工具 | Android Studio | **DevEco Studio** |
| 构建系统 | Gradle + AGP | **hvigor** |

所以只能重写，但**算法与数据模型可以 1:1 对应移植**——这也是本方案的重点：
把踩过坑、有测试保护的核心逻辑先搬过来，UI 和系统能力再逐个接。

## 三、关键技术决策

### 1. 日期运算：不用 `Date`，用「天数序号」

JS 的 `Date` 带时区与夏令时，做「第 N 周是几月几号」这类运算极容易出错。
`data/DateUtil.ets` 用 Howard Hinnant 的 `days_from_civil` 算法把日期转成
**自 1970-01-01 起的天数**，全部运算都是整数，与时区完全无关。

```ts
DateUtil.fromYmd(2026, 10, 29)   // → 20755
DateUtil.weekday(20755)          // → 4（周四）
DateUtil.addDays(...)            // 直接整数加减
```

**移植时要小心**：Android 版用的是 `java.time.LocalDate`（本身就无时区问题），
鸿蒙这边**不要**图省事改成 `new Date()` 做算术。

### 2. HTML 解析：自写表格提取器

鸿蒙没有 Jsoup。教务系统课表页是典型 table 布局，所以
`importer/HtmlTable.ets` 实现了够用的解析：

- 剥 `script` / `style` / 注释
- 抽 `<table>` → `<tr>` → `<td|th>`
- **`<br>` 转成换行**（课表单元格里一个格子常有多张课程卡片，靠换行保持结构）
- `colspan` 补空列保持列对齐
- 解码 `&nbsp;` 等实体 + 数字实体

局限：**不处理 `rowspan`**。如果遇到跨行合并的课表页，需要补这块（Android 版有 `expandTable`，
可以照搬逻辑）。

### 3. 周次必须存显式集合

教务系统的周次写法是不规则的：

```
4-5周,8周,11-13周(单),14-16周
```

**不能**只存 `startWeek=4, endWeek=16`——那样第 6、7、12 周会凭空多出课来。
`WeekParser.parse()` 展开成显式集合 `[4,5,8,11,13,14,15,16]`，
`Course.occursOnWeek()` 优先用它判断。

> 这个坑在 Android 版踩过两次（编辑课程时丢失、分享码不带周次），
> 鸿蒙版从数据结构上就带着 `weeks: number[]`，不会再犯。

### 4. 节假日：三个独立开关 + 补班日例外

| 开关 | 覆盖 |
|---|---|
| 屏蔽法定节假日 | 元旦/春节/清明/劳动/端午/中秋/国庆 |
| 屏蔽学校假期 | 校运会/寒假/暑假（GLTU 校历） |
| 屏蔽日常周末 | 周六、周日 |

**补班日（调休上班的周末）不受任何开关影响，一律照常上课** —— 这点很多课表 App 会做错。

### 5. 构建配置的版本号格式

`build-profile.json5` 里 `compatibleSdkVersion` 的格式**随 API 版本变化**：

| API 版本 | 写法 |
|---|---|
| 10 ~ 25 | `"5.0.0(12)"`（带括号） |
| **26 起** | **`"26.0.0"`（不带括号）** |

填错会报 `Specification Limit Violation`，错误信息里会写明正确格式。
