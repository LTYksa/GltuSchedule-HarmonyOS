## 一、壁纸存储（BackgroundImageStore.kt）

| 项 | Android 事实 |
|---|---|
| 路径 | `context.filesDir` 目录下，文件名常量 `FILE_NAME = "schedule_background.jpg"` |
| 权限 | 应用私有目录，**不需要任何存储权限** |
| exists | `file.exists() && file.length() > 0` |

**save(uri)**（当前 UI 无调用点，仅保留）：
`contentResolver.openInputStream(uri)` → 原样 `input.copyTo(output)` **不解码、不缩放、不重编码**；随后 `BitmapFactory.decodeFile(target.absolutePath) != null` 校验可解码，失败则 `target.delete()` 并返回 false；异常一律吞掉返回 false。

**saveBitmap(bitmap)**（实际使用的路径）：
`target.outputStream()` → `bitmap.compress(Bitmap.CompressFormat.JPEG, 92, out)`。**JPEG / quality = 92**。

**decodeForEdit(uri, maxSide = 2400)**（进裁切界面前的待编辑原图）：
- API 28+：`ImageDecoder.createSource(...)` → `decoder.allocator = ALLOCATOR_SOFTWARE` → `longest = max(info.size.width, info.size.height)`；若 `longest > maxSide`：
  ```kotlin
  var sample = 1
  while (longest / sample > maxSide) sample *= 2
  decoder.setTargetSampleSize(sample)
  ```
  自动应用 EXIF 方向（竖拍照片不躺倒）。
- 低版本回退：`inJustDecodeBounds = true` 读 bounds → 同一个 sample 循环（`longest/sample > 2400`）→ `inSampleSize` 解码。

**loadScaled(maxWidth = 1440)**（课表页显示用）：
```kotlin
val bounds = BitmapFactory.Options().apply { inJustDecodeBounds = true }
BitmapFactory.decodeFile(f.absolutePath, bounds)
var sample = 1
while (bounds.outWidth / sample > maxWidth * 2) sample *= 2   // 只看宽！阈值 1440*2 = 2880
val opts = BitmapFactory.Options().apply { inSampleSize = sample }
BitmapFactory.decodeFile(f.absolutePath, opts)
```
注意三点：**只按宽度判断**、阈值是 `maxWidth * 2`（2880）、`sample` 是 2 的幂。文件不存在返回 null。

**大小上限**：源码中**没有任何文件大小上限或校验**。唯一的"上限"是解码采样（编辑 2400 长边 / 显示 2880 宽），`save()` 只校验能不能解码。

**clear()**：`file(context).delete()`（忽略返回值）。

**状态流转**（ScheduleViewModel）：
- `_hasBackground = MutableStateFlow(BackgroundImageStore.exists(app))`
- `_backgroundVersion = MutableStateFlow(0)`
- `setBackground(uri)` → `save()`；`setBackgroundBitmap(bmp)` → `saveBitmap()`；成功后 `hasBackground = true`、`backgroundVersion += 1`
- `clearBackground()` → `clear()` + `hasBackground = false` + `backgroundVersion += 1`
- `backgroundVersion` 是 Compose 的重载触发器（见下）。

## 二、裁切界面（BackgroundCropDialog.kt）

### 2.1 交互全貌
- 全屏 `Dialog(usePlatformDefaultWidth = false, decorFitsSystemWindows = false)`，根容器纯黑 `fillMaxSize`。**vw/vh = 真实整屏 px**（含状态栏/导航栏），这是"输出比例 == 屏幕比例"的前提。
- `BoxWithConstraints` 取 `vw = maxWidth.toPx()`、`vh = maxHeight.toPx()`；`srcW/srcH` = 采样后位图宽高。
- `minScale = if (vw <= 0f || vh <= 0f) 1f else max(vw / srcW, vh / srcH)`（铺满屏幕的最小缩放，保证永不露黑边）。
- 初始 `scale = minScale`、`offset = Offset.Zero`。
- 手势 `detectTransformGestures`：
  ```kotlin
  val next = (scale * zoom).coerceIn(minScale, minScale * 8f)
  scale = next
  offset = clampOffset(offset + pan, next)
  ```
  → **缩放范围 [minScale, minScale × 8]**，双指缩放、单指/多指拖动一体。
- 边界限制：
  ```kotlin
  maxX = max(0f, (srcW * s - vw) / 2f)
  maxY = max(0f, (srcH * s - vh) / 2f)
  offset.coerceIn(-maxX, maxX) / (-maxY, maxY)
  ```
- 预览绘制：`left = size.width/2 + offset.x - srcW*scale/2`，`top` 同理；`withTransform{ translate(left, top); scale(scale, scale, pivot = Offset.Zero) }` 内 `drawImage(img, topLeft = Offset.Zero)`。
- 「铺满屏幕」按钮：`scale = minScale; offset = Offset.Zero`。
- 「使用这张」：`cropToViewport(...)`，非空 → `onConfirm(out)`，空 → `onCancel()`。

### 2.2 computeCropGeometry（纯函数，可单测）
签名：`(srcW: Int, srcH: Int, scale: Float, offsetX: Float, offsetY: Float, vw: Float, vh: Float) -> CropGeometry?`
返回 `CropGeometry(outW: Int, outH: Int, scale: Float, tx: Float, ty: Float)`

```
非法：vw <= 0 || vh <= 0 || srcW <= 0 || srcH <= 0 || scale <= 0  → null

outW = round(vw).coerceIn(720, 1440)
outH = (outW * (vh / vw)).roundToInt().coerceAtLeast(1)
k    = outW / vw
s    = scale * k
tx   = offsetX * k + outW / 2f - srcW * s / 2f
ty   = offsetY * k + outH / 2f - srcH * s / 2f
```
推导：图片左上角在视口中 = 视口中心 + offset − 原图尺寸·scale/2；视口点 p → 输出 `out = k*(p − 视口中心) + 输出中心`；合并得 `p_out = p_img*(scale*k) + offset*k + 输出中心 − srcSize*(scale*k)/2`。**先缩放到 scale*k、再平移**，顺序不能反（反了位移会被二次缩放）。

关键不变量：视口 (0,0) → 输出 (0,0)；视口 (vw,vh) → 输出 (outW,outH)。满足它同时保证 ①所见即所得 ②输出比例==屏幕比例，课表页 Crop 渲染不会二次裁切。

### 2.3 cropToViewport
```kotlin
val out = Bitmap.createBitmap(g.outW, g.outH, Bitmap.Config.ARGB_8888)
val canvas = Canvas(out)
val m = Matrix()
m.postScale(g.scale, g.scale)      // 先缩放

```
失败返回 null（调用方转 onCancel）。

### 2.7 CropGeometryTest 的 5 个断言（照搬清单）
公共夹具：`srcW = 4000, srcH = 3000, vw = 1080f, vh = 2340f` → `minScale = max(1080/4000, 2340/3000) = max(0.27, 0.78) = 0.78`

辅助函数（必须一起照搬）：
```
toOut(g, px, py) = (px * g.scale + g.tx, py * g.scale + g.ty)
imgLeftInView(scale, ox) = vw/2 + ox - srcW*scale/2
imgTopInView(scale, oy)  = vh/2 + oy - srcH*scale/2
viewToImg(v, left, scale) = (v - left) / scale
```

| # | 测试名 | 内容 | 断言条数 |
|---|---|---|---|
| 1 | `铺满时的四角映射` | `checkRoundTrip(minScale, 0f, 0f)` | 4 条 `assertEquals(期望, 实际, 1f)`：视口(0,0)→输出(0,0) 的 x、y；视口(vw,vh)→输出(outW,outH) 的 x、y |
| 2 | `放大并拖动后四角仍然对齐` | `checkRoundTrip(minScale*2.5f, 120f, -230f)` 和 `checkRoundTrip(minScale*5f, -400f, 160f)` | 8 条 `assertEquals(..., 1f)`（2 组 × 4 角） |
| 3 | `输出比例等于屏幕比例` | `g = computeCropGeometry(srcW, srcH, 1f, 0f, 0f, vw, vh)!!`；`assertEquals(vh/vw, outH/outW, 0.002)` | 1 条 |
| 4 | `竖屏与横屏都能算出合理输出` | 竖屏 `computeCropGeometry(1080, 2400, 1f, 0,0, 1080f, 2340f)` → `assertTrue(outH > outW)`（2340>1080）；横屏 `computeCropGeometry(4000, 3000, 1f, 0,0, 2000f, 1200f)` → `assertTrue(outH < outW)`（864<1440）、`assertEquals(1440, outW)` | 3 条 |
| 5 | `非法输入返回 null` | `assertNull` × 4：`(0,100,1,0,0,vw,vh)`、`(100,100,0,0,0,vw,vh)`、`(100,100,1,0,0,0,vh)`、`(100,100,1,0,0,vw,0)` | 4 条 |

`checkRoundTrip` 步骤：算出 g → 算 left/top → `viewToImg(0f,left,scale)`/`viewToImg(0f,top,scale)` 过 `toOut` 应为 (0,0)；`viewToImg(vw,left,scale)`/`viewToImg(vh,top,scale)` 过 `toOut` 应为 (outW,outH)。

## 四、主题

**三档模式**：`SchedulePreferences` 常量 `THEME_SYSTEM = 0 / THEME_LIGHT = 1 / THEME_DARK = 2`，存 SharedPreferences 文件 `"gltu_schedule_prefs"`，key `"theme_mode"`，默认 0。

**生效链路**：
1. `MainActivity.onCreate`：`AppThemeState.mode = SchedulePreferences.themeMode(this)`
2. `setContent { val dark = AppThemeState.isDark(isSystemInDarkTheme()); GltuScheduleTheme(darkTheme = dark) { ScheduleApp() } }`
3. `AppThemeState`：
   ```kotlin
   object AppThemeState {
       var mode by mutableIntStateOf(SchedulePreferences.THEME_SYSTEM)
       fun isDark(systemDark: Boolean) = when (mode) {
           THEME_LIGHT -> false; THEME_DARK -> true; else -> systemDark
       }
   }
   ```
   `mutableIntStateOf` 是 Compose 快照状态：`mode` 一变，读过它的 `setContent` 闭包重组 → 整棵树重组 → **即时换肤**。
4. `ScheduleViewModel.setThemeMode(mode)` 三件事：`_themeMode.value = mode`（抽屉回显）、`AppThemeState.mode = mode`（触发重组）、`SchedulePreferences.setThemeMode`（持久化）。

**动态取色（Material You）**：
```kotlin
dynamicColor && Build.VERSION.SDK_INT >= Build.VERSION_CODES.S(31)
  → if (darkTheme) dynamicDarkColorScheme(context) else dynamicLightColorScheme(context)
darkTheme → DarkColorScheme ; else → LightColorScheme
```
即 **Android 12 / API 31+ 才启用**，从系统壁纸取色；启用时**静态色完全不参与**。回退色（Color.kt 全文）：
- 深色：`Blue80 = #FFA8C4E0`（primary）、`BlueGrey80 = #FFBFC7D4`（secondary）、`Amber80 = #FFE8C98A`（tertiary）
- 浅色：`Blue40 = #FF4E6E9E`、`BlueGrey40 = #FF5B6472`、`Amber40 = #FF9A6B1F`
- `darkColorScheme(...)` / `lightColorScheme(...)` **只覆盖了 primary / secondary / tertiary 三个 token**，其余（surface/onSurface/outlineVariant/error…）都是 Material 3 的默认值。typography 用工程内的 `Typography`。

**深色下的具体色值**（能引用到源码的只有 3 个）：`#A8C4E0` / `#BFC7D4` / `#E8C98A`。其余 token 属于 Material3 `darkColorScheme()` 默认（非本项目源码），鸿蒙侧需要自行补一张表（见五）。

### 5.1 壁纸：选图 → PixelMap → 沙箱 → 显示

**选图**（不要用已废弃的 `picker.PhotoViewPicker`，API 12 起用 photoAccessHelper）：
```ts
import { photoAccessHelper } from '@kit.MediaLibraryKit';

const picker = new photoAccessHelper.PhotoViewPicker();
const opt: photoAccessHelper.PhotoSelectOptions = {
  MIMEType: photoAccessHelper.PhotoViewMIMETypes.IMAGE_TYPE,
  maxSelectNumber: 1
};
const res: photoAccessHelper.PhotoSelectResult = await picker.select(opt);
const uri: string = res.photoUris.length > 0 ? res.photoUris[0] : '';
if (uri.length === 0) { this.message = '未选择图片'; return; }
this.cropUri = uri;               // 进裁切界面
```
`uri` 形如 `file://media/Photo/...`，是**临时授权**，不要持久化，必须立刻解码/拷贝。

**存储**（`BackgroundImageStore.ets`，与 Android 同名同路径）：
```ts
import { fileIo as fs } from '@kit.CoreFileKit';
import { image } from '@kit.ImageKit';
import { common } from '@kit.AbilityKit';

const FILE_NAME: string = 'schedule_background.jpg';

export class BackgroundImageStore {
  private static path(ctx: common.UIAbilityContext): string {
    return ctx.filesDir + '/' + FILE_NAME;
  }

  static exists(ctx: common.UIAbilityContext): boolean {
    const p = BackgroundImageStore.path(ctx);
    return fs.accessSync(p) && fs.statSync(p).size > 0;
  }

  /** 待裁切原图：maxSide=2400，2 的幂采样，顺带按 EXIF 摆正 */
  static async decodeForEdit(ctx: common.UIAbilityContext, uri: string,
                             maxSide: number = 2400): Promise<image.PixelMap | undefined> {
    let file: fs.File | undefined = undefined;
    let src: image.ImageSource | undefined = undefined;
    try {
      file = fs.openSync(uri, fs.OpenMode.READ_ONLY);
      src = image.createImageSource(file.fd);
      const info = src.getImageInfoSync(0);
      const longest = Math.max(info.size.width, info.size.height);
      let sample = 1;
      while (longest / sample > maxSide) { sample *= 2; }

      let rotate = 0;
      try {
        const o = await src.getImageProperty(image.PropertyKey.ORIENTATION);
        if (o === 'Right-top') { rotate = 90; }
        else if (o === 'Bottom-right') { rotate = 180; }
        else if (o === 'Left-bottom') { rotate = 270; }
      } catch (e) { rotate = 0; }

      const opt: image.DecodingOptions = {
        sampleSize: sample,
        rotate: rotate,                                  // 顺时针角度
        editable: true,                                  // 必须 true，后面要读/写像素
        desiredPixelFormat: image.PixelMapFormat.RGBA_8888
      };
      return src.createPixelMapSync(opt);
    } catch (e) {
      return undefined;
    } finally {
      if (src !== undefined) { src.release(); }
      if (file !== undefined) { fs.closeSync(file); }
    }
  }

  /** 写盘：JPEG quality 92（对齐 Android saveBitmap） */
  static savePixelMap(ctx: common.UIAbilityContext, pm: image.PixelMap): boolean {
    const path = BackgroundImageStore.path(ctx);
    let file: fs.File | undefined = undefined;
    try {
      file = fs.openSync(path,
        fs.OpenMode.CREATE | fs.OpenMode.READ_WRITE | fs.OpenMode.TRUNC);  // TRUNC 不能省
      const packer = image.createImagePacker();
      const opt: image.PackingOption = { format: 'image/jpeg', quality: 92 };
      packer.packToFileSync(pm, file.fd, opt);   // 无 Sync 版就用 await packToFile
      packer.release();
      return true;
    } catch (e) {
      return false;
    } finally {
      if (file !== undefined) { fs.closeSync(file); }
    }
  }

  /** 显示用采样：严格照搬"只看宽、阈值 maxWidth*2" */
  static loadScaled(ctx: common.UIAbilityContext,
                    maxWidth: number = 1440): image.PixelMap | undefined {
    const path = BackgroundImageStore.path(ctx);
    if (!BackgroundImageStore.exists(ctx)) { return undefined; }
    let src: image.ImageSource | undefined = undefined;
    try {
      src = image.createImageSource(path);
      const info = src.getImageInfoSync(0);
      let sample = 1;
      while (info.size.width / sample > maxWidth * 2) { sample *= 2; }
      return src.createPixelMapSync({ sampleSize: sample });
    } catch (e) {
      return undefined;
    } finally {
      if (src !== undefined) { src.release(); }
    }
  }

  static clear(ctx: common.UIAbilityContext): void {
    const path = BackgroundImageStore.path(ctx);
    if (fs.accessSync(path)) { fs.unlinkSync(path); }
  }
}
```
要点：`packToFile` 若只有异步版就 `await`；`imageSource` / `packer` 用完 `release()`；沙箱读写**不需要任何权限**（别加 `ohos.permission.READ_IMAGEVIDEO`）。

**显示**（与 Android `ContentScale.Crop` 等价）：

```ts
  Image(this.bgPixelMap)
    .objectFit(ImageFit.Cover)
```

### 5.2 裁切：`common/CropGeometry.ets`（纯函数，逐行照搬）

```ts
export class CropGeometry {
  outW: number = 0; outH: number = 0;
  scale: number = 0; tx: number = 0; ty: number = 0;
}

function clamp(v: number, lo: number, hi: number): number {
  return v < lo ? lo : (v > hi ? hi : v);
}

export function computeCropGeometry(srcW: number, srcH: number,
                                    scale: number, offsetX: number, offsetY: number,
                                    vw: number, vh: number): CropGeometry | undefined {
  if (vw <= 0 || vh <= 0 || srcW <= 0 || srcH <= 0 || scale <= 0) { return undefined; }
  const outW = clamp(Math.round(vw), 720, 1440);
  const outH = Math.max(1, Math.round(outW * (vh / vw)));
  const k = outW / vw;
  const s = scale * k;
  const g = new CropGeometry();
  g.outW = outW; g.outH = outH; g.scale = s;
  g.tx = offsetX * k + outW / 2 - srcW * s / 2;
  g.ty = offsetY * k + outH / 2 - srcH * s / 2;
  return g;
}
```

**手势**（累计语义 + vp→px 换算，这两个坑必须处理）：
```ts
@State scale: number = 1;        // 单位：图片px → 视口px
@State offX: number = 0;         // 单位：px
@State offY: number = 0;
private minScale: number = 1;
private pinchBase: number = 1;   // 手势开始时的 scale
private panBaseX: number = 0;
private panBaseY: number = 0;
private vwPx: number = 0;        // 视口物理宽（px）
private vhPx: number = 0;        // 视口物理高（px）

build() {
  Stack() { /* 预览层 */ }
    .width('100%').height('100%').clip(true)
    .onAreaChange((_, area: Area) => {
      const ui = this.getUIContext();
      this.vwPx = ui.vp2px(area.width as number);
      this.vhPx = ui.vp2px(area.height as number);
      this.minScale = Math.max(this.vwPx / this.srcW, this.vhPx / this.srcH);
      this.scale = this.minScale; this.offX = 0; this.offY = 0;
    })
    .gesture(
      GestureGroup(GestureMode.Parallel,
        PinchGesture({ fingers: 2 })
          .onActionStart(() => { this.pinchBase = this.scale; })
          .onActionUpdate((e: GestureEvent) => {
            const next = clamp(this.pinchBase * e.scale, this.minScale, this.minScale * 8);
            this.scale = next;
            this.offX = this.clampOff(this.offX, this.srcW * next, this.vwPx);
            this.offY = this.clampOff(this.offY, this.srcH * next, this.vhPx);
          }),
        PanGesture({ fingers: 1, distance: 1 })
          .onActionStart(() => { this.panBaseX = this.offX; this.panBaseY = this.offY; })
          .onActionUpdate((e: GestureEvent) => {
            const ui = this.getUIContext();
            this.offX = this.clampOff(this.panBaseX + ui.vp2px(e.offsetX),
                                      this.srcW * this.scale, this.vwPx);
            this.offY = this.clampOff(this.panBaseY + ui.vp2px(e.offsetY),
                                      this.srcH * this.scale, this.vhPx);
          })
      )
    )
}

/** maxX = max(0, (imgLen - viewLen) / 2)，与 Android clampOffset 等价 */
private clampOff(v: number, imgLen: number, viewLen: number): number {
  const m = Math.max(0, (imgLen - viewLen) / 2);
  return clamp(v, -m, m);
}
```

**预览（最简实现，推荐）**——用 `ImageFit.Cover` 承担 minScale，再把 scale/offset 叠上去：
```ts
Image(this.srcPixelMap)
  .width('100%').height('100%')
  .objectFit(ImageFit.Cover)
```

**预览（Canvas 版，逐字对齐 Android）**：注意 ArkUI `CanvasRenderingContext2D` **坐标是 vp**：

```ts
  new CanvasRenderingContext2D(new RenderingContextSettings(true));
```

**裁切产物**，三种写法：

A. **PixelMap crop + scale（推荐，等价于 Android 的 Matrix）**
```ts
const g = computeCropGeometry(this.srcW, this.srcH, this.scale, this.offX, this.offY,
                              this.vwPx, this.vhPx);
if (g === undefined) { return undefined; }
const pm = this.srcPixelMap.cloneSync();          // cropSync/scaleSync 是原地修改，先克隆
// 视口(0,0) 对应图像坐标 = -tx/s ；可见区域尺寸 = outW/s
const x0 = -g.tx / g.scale, y0 = -g.ty / g.scale;
const w0 = g.outW / g.scale, h0 = g.outH / g.scale;
const cx = Math.max(0, Math.ceil(x0));                       // 向内取整，绝不越界
const cy = Math.max(0, Math.ceil(y0));
const cw = Math.min(this.srcW - cx, Math.floor(x0 + w0) - cx);
const ch = Math.min(this.srcH - cy, Math.floor(y0 + h0) - cy);
pm.cropSync({ x: cx, y: cy, size: { width: cw, height: ch } });
pm.scaleSync(g.outW / cw, g.outH / ch);                      // 缩放到精确输出尺寸
return pm;
```
（`cropSync` 的 `region` 必须是整数且不超过图片宽高；`scaleSync(x,y)` 的参数是"缩放后/缩放前"的倍数。取整会带来 ≤1px 偏差，肉眼不可见；介意的话 scale 后再 `cropSync` 居中对齐到 `outW×outH`。）

B. **OffscreenCanvas（等价于 Android 的 Canvas + Matrix）**
```ts
const off = new OffscreenCanvas(g.outW, g.outH);
const c = off.getContext('2d');
c.drawImage(this.srcPixelMap,
            0, 0, this.srcW, this.srcH,      // 源：整图
            0, 0, g.outW, g.outH);           // 目标：整幅输出
const out = c.getPixelMap(0, 0, g.outW, g.outH);   // API 12+
```
（`drawImage` 的 9 参形式支持 PixelMap；`getPixelMap` 需要 API 12+，取不到就退回 `toDataURL('image/jpeg', 0.92)` + base64 解码写文件。注意 OffscreenCanvas 的坐标同样按 vp 语义，但这里源/目标矩形都用"整图↔整幅输出"，比例已由 outW/outH 决定，不受单位影响。）

C. **buffer 逐像素重采样（公式与单测完全一致，最可控）**
```
readPixelsToBufferSync(srcBuf)            // PixelMap 用 RGBA_8888 创建，行可能有 stride 填充
for (oy = 0; oy < outH; oy++)
  for (ox = 0; ox < outW; ox++) {
     px = (ox - g.tx) / g.scale            // 由 out = p*s + t 反解
     py = (oy - g.ty) / g.scale
     // 最近邻取样写 outBuf
  }
image.createPixelMap(outBuf, { size: { width: outW, height: outH },
                               srcPixelFormat: image.PixelMapFormat.RGBA_8888,
                               pixelFormat: image.PixelMapFormat.RGBA_8888,
                               editable: true })
```
1080×2340 ≈ 253 万次循环，一次性操作可接受；行 stride 用 `pm.getBytesNumberPerRow()` / `pm.getPixelBytesNumber()`。

**输出尺寸**：完全照搬 —— `outW = clamp(round(vw_px), 720, 1440)`，`outH = round(outW * vh/vw)`。

**界面文案/参数**（照搬 2.5 的数值与原文，dp→vp、sp→fp）：
- 根 `Stack` 纯黑；顶部 `.linearGradient({ angle: 180, colors: [['#B8000000', 0.0], ['#00000000', 1.0]] })` + `padding({left:20,right:20,top:14,bottom:14})`
- 标题 `'裁切壁纸'` 20fp 粗体白；副标题 `'双指缩放、单指拖动。整屏所见即最终壁纸，会自动铺满背景。'` 13fp 白 α0.85

### 5.5 鸿蒙限制与坑（务必逐条确认）
1. **单位不一致**：`CanvasRenderingContext2D` 绘图坐标是 **vp**；`GestureEvent.offsetX/offsetY/pinchCenterX/Y` 也是 **vp**（`scale` 无量纲）；Android 侧全是 px。屏幕物理尺寸用 `display.getDefaultDisplaySync()`（px）或 `uiContext.vp2px()`。**建议全部状态用 px，只在绘制/布局时换算 vp**。
2. **裁切比例必须等于壁纸实际显示区域的比例**。鸿蒙版有底部导航，若壁纸只铺课表内容区，`vw/vh` 就必须取该内容区尺寸（`onAreaChange` 拿），不能照抄 Android 的整屏。这是最容易被忽略、也最影响观感的一条。
3. `PixelMap.cropSync/scaleSync/rotateSync/flipSync` 都是**原地修改**，要保留原图先 `cloneSync()`。
4. `cropSync` 的 region 必须是**整数且不越界**（≤ 图片宽高）→ 向内取整；`scaleSync` 后尺寸可能差 1px，必要时再 crop 一次对齐。
5. `readPixels/writePixels` 固定 **BGRA_8888**；`readPixelsToBuffer/writeBufferToPixels` 按 PixelMap 自身格式。行可能有 **stride 填充**，用 `getBytesNumberPerRow()` / `getPixelBytesNumber()`，不要假设 `width*4`。
6. PixelMap **序列化上限 128MB**（宽×高×每像素字节）；解码大图必须采样（保留 2400 / 1440 两个上限）。
7. PixelMap **跨线程**（taskpool/worker）后，原线程不能再调用它的任何接口。
8. `packToFile` 之后要 `fileIo.closeSync(file)`；`PixelMap` / `ImageSource` / `ImagePacker` 用完 `release()`。
9. 覆盖写文件必须带 `fs.OpenMode.TRUNC`（Android 的 `outputStream()` 默认截断，鸿蒙不写 TRUNC 会残留旧字节）。
10. `PhotoViewPicker` **不需要权限**，不要申请 `ohos.permission.READ_IMAGEVIDEO`；返回的 uri 是临时授权，必须立刻处理。
11. 深色：`resources/dark/` **不能为空**，否则系统组件在深色模式下仍保持浅色；代码里手动 `setColorMode` 后**不会**收到 `onConfigurationUpdate` 回调（官方文档明确），所以"跟随系统"必须用 `COLOR_MODE_NOT_SET`，"跟随系统"的即时刷新要靠 `onConfigurationUpdate` + AppStorage。
12. `setColorMode` 只影响系统组件与 `$r()` 资源解析；`Palette.ets` 里手写的 `C.xxx` 字符串**不会自动变**，深色模式必须自己处理。
13. 裁切屏要铺满整屏才能保证 `vw/vh` = 整屏：鸿蒙用 `window.setWindowLayoutFullScreen(true)` 或对根容器 `.expandSafeArea([SafeAreaType.SYSTEM], [SafeAreaEdge.TOP, SafeAreaEdge.BOTTOM])`；顶/底工具条再用 `.expandSafeArea` 的反向思路或 padding 让出状态栏/导航栏。
14. **Material You 动态取色在鸿蒙无对等 API**。
15. 有壁纸时课程块底色 0.13 → 0.34 的落点：`Index.ets` 的 `courseCell()` 里 `.backgroundColor(Col.alpha(this.cellBase(item), item.dimmed ? 0.10 : 0.13))`，以及 `dayList()` 里 `.backgroundColor(Col.alpha(this.rowAccent(c), c.occursOnWeek(this.week) ? 0.13 : 0.10))`；同时把 `onWallpaper` 作为 `@State hasWallpaper: boolean` 贯穿到这两个 Builder。
16. 蒙层渐变角度：ArkUI `linearGradient` 的 `angle` **0 度是从下往上**，从上到下要写 `angle: 180`（也是默认值），`colors` 是 `Array<[颜色, 位置]>`。
